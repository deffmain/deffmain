# 👨🏻‍💻 Micael Martins

**`Engenharia de Software | Desenvolvedor Java`**

Estudante de **Engenharia de Software**, com foco no desenvolvimento de aplicações utilizando **Java e Spring Boot**.

Tenho experiência acadêmica e prática no desenvolvimento de aplicações, especialmente na construção de **APIs REST**, integração com **bancos de dados relacionais**, implementação de regras de negócio e organização de código.

Atualmente, venho aprofundando meus conhecimentos em:

* ☕ **Java**
* 🌱 **Spring Boot**
* 🔗 **APIs REST**
* 🗄️ **PostgreSQL e SQL**
* 🧪 **Testes automatizados**
* 🏗️ **Boas práticas e arquitetura de software**
* 🌐 **HTML, CSS e JavaScript**

Também estudo e experimento o uso de **Inteligência Artificial no desenvolvimento de software**, buscando compreender como ferramentas de IA podem apoiar produtividade, automação e construção de soluções.

### 🚀 Sobre meus projetos

Utilizo meus projetos como forma de transformar conhecimento teórico em aplicações práticas, buscando desenvolver soluções com preocupação em **organização, manutenção, segurança e qualidade de código**.

Meu objetivo profissional é atuar como **desenvolvedor de software**, contribuindo com projetos reais enquanto continuo aprimorando minhas habilidades técnicas e adquirindo experiência com desenvolvimento em equipe.
